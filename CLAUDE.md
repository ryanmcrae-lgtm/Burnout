# Planet Burnout — Claude Code Context

Companion site for the book *Welcome to Planet Burnout*. A Fallout Pip-Boy
themed single-page site that takes a short story from the visitor and
returns a military / sci-fi call sign generated by Claude, then surfaces a
HubSpot form for lead capture.

## How It Works

1. Visitor types a short story (≤500 chars) into the textarea in
   `index.html`.
2. JS posts JSON `{ story }` to `/.netlify/functions/generate-callsign`.
3. The function calls `anthropic.messages.create(...)` with a Planet Korob
   call-sign prompt and returns `{ callsign }` (uppercased, trimmed).
4. The UI shows the call sign and reveals the HubSpot form for email
   capture.

## Commands

```bash
npm install             # install deps
npm run dev             # netlify dev — serves at http://localhost:8888
```

There is no test suite, linter, or build step configured.

## Environment Variables

- `ANTHROPIC_API_KEY` — required server-side. Set in:
  - Local: `.env` (see `.env.example`)
  - Netlify: Site configuration → Environment variables
  - Vercel: `vercel env add ANTHROPIC_API_KEY`

The key is **only** referenced from the serverless function. Never expose
it in `index.html`.

## Conventions & Gotchas

- **No build tools.** Edit `index.html` directly — CSS and JS are inline.
- **Two copies of the function.** `netlify/functions/generate-callsign.js`
  and `api/generate-callsign.js` are intentional (Netlify vs Vercel) but
  drift is a real risk. As of this writing they disagree on model:
  - `netlify/functions/generate-callsign.js` → `claude-3-haiku-20240307`
  - `api/generate-callsign.js` → `claude-3-5-sonnet-20241022`
  Decide which is canonical before changing prompts.
- **Model choice.** README mentions Claude 3.5 Sonnet, the deployed Netlify
  function uses Haiku. Cost is cited as ~$0.003/call in `DEPLOYMENT.md`,
  which matches Sonnet pricing, not Haiku — worth resolving.
- **Frontend endpoint is hardcoded.** `index.html` line ~330 calls
  `/.netlify/functions/generate-callsign`. Switching to Vercel requires
  editing that path to `/api/generate-callsign`.
- **SPA redirect.** `netlify.toml` rewrites all routes to `/index.html` —
  fine because there's only one page, but be aware if you add real routes.
- **Theme color.** Pip-Boy green `#00ff00` is used throughout `index.html`.
  Change it there if rebranding.
- **Character limit.** `maxlength="500"` on the textarea (line ~276) and
  the counter UI must stay aligned with whatever the prompt expects.
- **Prompt rules.** Call sign must be 1–3 words, no quotation marks,
  uppercase, gritty/military/sci-fi tone. Edit in
  `netlify/functions/generate-callsign.js` around line 33.

## Working With Claude Code

When asked to make changes:

- Confirm whether changes should land in the Netlify function, the Vercel
  copy, or both.
- Prefer editing `index.html` in place over splitting it into separate
  CSS/JS files unless explicitly asked — the single-file shape is part of
  the project's "no build tools" stance.
- Don't add a test framework, bundler, or TypeScript without asking.
- Don't commit `.env` or any real `ANTHROPIC_API_KEY`.
- Active development happens on `claude/export-notes-obsidian-Mt9WC` per
  current branch policy.
